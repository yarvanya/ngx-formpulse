# Security policy

## Supported versions

Only the latest released version of `ngx-formpulse` receives security fixes.

## Reporting a vulnerability

Report vulnerabilities privately through
[GitHub security advisories](https://github.com/yarvanya/ngx-formpulse/security/advisories/new).
Do not open a public issue. You will get an answer within 7 days.

## Scope

FormPulse performs no network requests and never logs, stores or transmits validated values.
Releases are published only from GitHub Actions with npm provenance.
