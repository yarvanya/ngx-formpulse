# Changelog

All notable changes to `ngx-formpulse` are documented here. The project follows
[Semantic Versioning](https://semver.org/).

## Unreleased

### Added

- FP-1: `fpPostCode` validator for Reactive Forms and Signal Forms with postal-code data for 174
  countries from Google libaddressinput, messages in 7 locales, sandbox page and validator generator.
- FP-0: workspace, validation core, Reactive Forms and Signal Forms adapters, locale packs
  (uk, es, pt, pl, de, fr), `provideFormPulse`, `FpLocale`, `FpCountry`, sandbox documentation site,
  quality gates and CI.
