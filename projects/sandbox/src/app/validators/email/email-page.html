fpEmail

Email addresses people really use, without the typos that the browser and Validators.email let through.

Reactive Forms Signal Forms 7 languages HTML5 + RFC 5321 / 5322

What it does

  • Follows the HTML5 type=email grammar, tightened with the RFC rules for dots and lengths.
  • Requires a top-level domain: user@company is invalid, user@company.com is valid.
  • Rejects a dot at the start, at the end or twice in a row before @.
  • ASCII only; an international domain is accepted in punycode, such as xn--j1amh, the punycode form of the Ukrainian .ukr domain.
  • Empty values are valid; combine with a required validator for mandatory fields. A value of spaces only is invalid.
  • Tolerant by default: surrounding spaces are ignored. strict: true checks the value exactly as entered.
  • The control value is never modified.
