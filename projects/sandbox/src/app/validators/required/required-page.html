asterisk

fpRequired

Tells a filled field from an empty one for text, numbers, checkboxes, lists, files and dates.

Reactive Forms Signal Forms 7 languages Every value type

What it does

  • Rejects null, undefined, empty text and text of spaces only.
  • Accepts 0 and false: a quantity of zero and the answer "no" are real values.
  • Rejects an untouched checkbox (null), an empty selection and no chosen file.
  • Rejects NaN and an invalid date; accepts any object, such as a selected record.
  • In Signal Forms it also marks the field as required, so the input gets the required attribute.
  • The control value is never modified.

Required marker in Reactive Forms

Angular shows the asterisk only for its own Validators.required, and the required attribute would add that validator too. Add a visual asterisk to the label; on a plain input also set aria-required (Angular Material manages it on its own fields).
