fpPostCode

Postal codes of 174 countries, checked against the format of one country or of any.

Reactive Forms Signal Forms 7 languages Google libaddressinput

What it does

  • With a country, the value must match that country's postal-code format.
  • Without a country, the value must match the format of at least one supported country.
  • Empty values are valid; combine with a required validator for mandatory fields. A value of spaces only is invalid.
  • A country without postal codes accepts any other value.
  • In Signal Forms the country can follow another field: fpPostCode(path.postCode, () => model().country).
  • Tolerant by default: surrounding spaces and letter case are ignored. strict: true matches exactly.
  • The control value is never modified.
