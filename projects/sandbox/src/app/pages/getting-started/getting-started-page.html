Getting started

Three steps from install to localized validation messages.

1

1. Install

FormPulse has no runtime dependencies. It needs only @angular/core and @angular/forms.

 2

2. Use a validator

No setup is required. Import a validator and add it to a control; every error message is English by default.

 3

3. Change the language (optional)

Register the locale packs you need and choose the default locale. Packs you do not import never reach your bundle. A single validator can still override the locale inline.

Available locales: English, Ukrainian, Spanish, Portuguese, Polish, German, French.
